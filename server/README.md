全試験・候補実行・DB接続/適用・起動停止・公開は保留です。性能は測定していません。ログ・記録・旧版・backup・partialを保持し、既存8値と本番運用値は承認していません。[セッション保護](../セッション保護/仕様.md)、[CSV](../応答検査/CSV保存前の照合.md)、[日時](../応答検査/日時の形式.md)も継続します。
