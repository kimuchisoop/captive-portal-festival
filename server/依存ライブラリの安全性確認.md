# 依存ライブラリの安全性確認

2026年10月19日 / 0.7.0の固定したPython依存12パッケージを対象に、PyPIのリリース別APIとOSVへ照会しました。照会に送信したのは公開パッケージ名と版だけです。利用者・設定・ログ・鍵は送信していません。

旧cryptography 46.0.7には7件のレコードがあり、別名をまとめると4グループでした。Fernetの現在の実装経路で全件が悪用可能という意味ではありません。PKCS#7復号とX.509検証の注意情報は、このアプリで直接利用していない機能に関するものです。同梱OpenSSLの注意情報も含むため、固定版を50.0.2へ更新しました。

| 開発元の注意情報 | 内容の要約 | 修正を含む版 |
|---|---|---|
| [GHSA-537c-gmf6-5ccf](https://github.com/pyca/cryptography/security/advisories/GHSA-537c-gmf6-5ccf) | 配布wheelに同梱するOpenSSL | 48.0.1 |
| [GHSA-g6cj-pr64-35w5](https://github.com/pyca/cryptography/security/advisories/GHSA-g6cj-pr64-35w5) | PKCS#7復号のエラー応答・時間差 | 50.0.0 |
| [GHSA-jwv3-5hgf-82ww](https://github.com/pyca/cryptography/security/advisories/GHSA-jwv3-5hgf-82ww) | 証明書の経路構築による処理量増加 | 49.0.0 |
| [GHSA-m2h6-j472-rp4c](https://github.com/pyca/cryptography/security/advisories/GHSA-m2h6-j472-rp4c) | ワイルドカードと証明書名の制約 | 49.0.0 |

更新後はPyPIとOSVの照会対象12パッケージで既知の該当情報を検出せず、配布取り下げもありませんでした。依存関係は新しい仮想環境へ導入し、pip checkで不整合がないことを確認しました。以前の46.0.7で作成した実在のバックアップを、新しい50.0.2で認証付き復号・形式検査しました。旧版・旧鍵・暗号文は保持しています。

対象は固定したPythonパッケージです。OS、Python本体とそのOpenSSL、MySQLサーバー、Nginx、ファームウェア、未公表の問題は別途確認が必要です。「検出なし」は安全の保証ではありません。照会時点の記録として扱い、公開前や依存版変更後に再確認してください。起動時に自動で外部照会する機能や、定期通知の設定は追加していません。
