# 画面・多言語・時間帯集計

0.9.0 / 2026年10月20日 / MySQL・DB形式4を継続

## 来場者向け画面

日本語、English、やさしい日本語を選べます。やさしい日本語は操作案内だけを変更し、規約本文は日本語の原文を表示します。日本語・英語の規約本文を今回書き換えていません。承認前の仮文面を継続します。

文字の「大きく」は本文を標準の200%にします。ブラウザー自体の拡大操作も制限していません。「高コントラスト」は背景を黒、文字を白へ変更します。どちらもその画面内だけの設定で、端末へ個人情報や選択履歴を保存しません。

最初のTabで「本文へ移動」を選び、Enterで本文へ進めます。規約欄はTabで選択し、上下キーやPage Downでスクロールできます。Tabで外へ移動でき、スクロール末尾への到達を同意の条件にしていません。チェックボックスはSpaceで切り替え、次のTabから保存ボタンへ進めます。表示だけでは同意を保存しません。

「画面が進まない・文字が読みにくいとき」には、文字・配色とスタッフへの相談を案内します。正式なSSID、接続先、会期、問い合わせ窓口は未確定です。スタッフは学校側が確認した案内を使ってください。

## 言語と保存状態

| 状態 | 動作 |
|---|---|
| 保存前に言語を変更 | 規約を読み直し、同意のチェックを解除。読み込み中の保存は不可 |
| 読み込み中に別の言語を選択 | 最後に選択した言語だけを反映。遅れて届いた古い応答を無視 |
| 保存結果が不明 | 同じ内容・同じ再試行キーで再確認。確認まで言語変更を停止 |
| 保存成功後、通信状態の取得だけ失敗 | 保存成功を保持し、通信状態を確認できなかったことを別に表示 |
| 保存後に言語を変更 | 同意済みのチェック、受付番号、保存した規約の版・言語を保持。新しい同意を作らない |

保存した同意の言語はjaまたはenです。「やさしい日本語」で同意した場合、表示する原文に合わせjaになります。案内の選択を新たな個人別ログに保存しません。

本番の通信許可は未接続です。「保存しました」を「インターネット接続に成功しました」と説明しないでください。確認用リンクは期限付き・一つのブラウザー用です。無効な場合は運営者が新しい確認用リンクを発行します。

## 運営者向け時間帯集計

ログイン後「当日の運営」に「時間帯別の同意・エラー件数」が表示されます。日付を選んで「集計を更新」を押します。閲覧・運用・記録・設定管理の4役割で表示できます。ログアウト時に表示内容を消します。記録そのものは削除しません。

| 数値 | 定義 |
|---|---|
| 同意保存 | 選択日の日本時間00:00以上、翌日00:00未満に保存された同意行の数。全イベント分の保存件数 |
| 4xx応答 | 来場者向け/v1/ APIでアプリが返し、記録できた400～499の応答。入力・期限・認証等も含む |
| 5xx応答 | 同じ範囲で記録できた500～599の応答。処理不能・受付停止等も含む |

24個の1時間枠を日本時間で表示します。同じ端末の再試行もエラー応答ごとに数えます。同じ再試行キーで同意を再確認しても同意行を増やしません。個人・端末・IP・Cookie・受付番号・自由記入・URLを集計値へ追加していません。返す値は時刻と件数だけです。

エラー集計の保存先は既存MySQLのmetaテーブルです。キーは`usage:v1:UTCの時刻枠:分類`、値は件数です。集計開始日時も記録します。新しいテーブルやDB形式の更新は不要です。バックアップ・復元でmetaを保全するため、集計も引き継げます。0.8.0へ戻した期間の新しいエラーは収集されません。

エラー収集は0.9.0以降のアプリで応答が作られた範囲に限ります。管理API、静的ファイル、NginxやAPでの拒否、アプリへ到達しない通信、DBに保存できなかったエラーは含みません。保存失敗時は元の応答を変えず、その起動中に記録できなかった件数を別表示します。この補助件数は再起動でリセットされます。集計開始前の0や、記録できなかった時間帯の0を「障害なし」と扱わないでください。

同意の件数は接続人数、同時接続数、通信量ではありません。回線負荷・APの利用状況は機器から取得する必要があり、現在は未接続です。集計の取得は手動更新です。個人別の行動分析や外部への送信は追加していません。

## 確認した範囲と実機用の記入票

PCのブラウザーで320×568、390×844、844×390、1280×900の表示、200%文字、キーボード操作、翻訳切り替え、保存後の状態、管理側の表とログアウトを確認しました。アクセシビリティツリーで名前、見出し、規約領域、状態通知を確認しています。読み上げソフトの音声やiPhone・Androidの実機の動作を確認したものではありません。

| 対象 | 記入するもの | 現状 |
|---|---|---|
| iPhone / iPad | 機種・OS版、Wi-Fiの簡易画面、Safari、縦横、文字拡大、同意・再表示 | 実機確認待ち |
| Android | 機種・OS版、Wi-Fiログイン画面、Chrome、縦横、文字拡大、同意・再表示 | 実機確認待ち |
| 読み上げ | VoiceOver・TalkBack・NVDA等の版、読み順、名前、状態通知、規約から抜ける操作 | 音声確認待ち |
| 無通信・遅い通信 | 読み込み表示、再試行、二重保存防止、受付番号の保持 | コード上の異常応答・再試行試験済み。実端末は確認待ち |

簡易ブラウザーを閉じたりキャンセルした際の挙動はOS側で異なります。勝手にOSの安全設定を変更せず、学校側が確定した正式な案内に従います。[AppleのキャプティブWi-Fi案内](https://support.apple.com/en-gb/102554)、[AndroidのWi-Fi接続案内](https://support.google.com/android/answer/9075847)を参照してください。
