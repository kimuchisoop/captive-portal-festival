ACCOUNT SECURITY
自分の追加認証
登録・再登録・紛失時の復旧は、保護されたサーバー端末で行います。登録用の秘密情報はこの画面やログへ表示しません。


ACCESS OPERATIONS
許可・取り消し
最新100件。受付側で失効させても、APでの切断完了を意味しません。


CONSENT RECORDS
処理期限内の記録を簡易CSVで取得
取得時点で処理期限内の記録を、最大1,000件ずつ取得します。ページ間で対象は固定されません。期限を過ぎた記録は保持されています。期間を指定して対象を固定する場合は、下の「条件を指定した固定CSV」を使ってください。CSV生成の記録は、端末への保存完了を意味しません。


BACKUPS
バックアップ一覧・検証結果
復号と復元の検証日時・結果を分けて表示します。復元の確認は、手順に従い別の空DBへ実際に復元して行います。ファイルは削除しません。


EVENT-DAY CHECKS
当日の運営チェック
開始前・開催中・終了後の確認内容を共有します。担当者の確認記録であり、APの実機状態や本番受付の設定は変更しません。
表示を切り替えると未保存の入力を置き換えます。個人情報・パスワードは記入しないでください。

SUPPORT SUMMARY
障害調査資料を作成
稼働状態・保存件数・通知の種類・MySQL診断の結果をまとめます。ログ本文、自由記入、利用者名、接続先、パスワード、鍵、Cookieは含めません。
資料はこのサーバーに保存します。外部へ自動送信しません。ダウンロード後の共有先は運営者が確認してください。


OPERATION HISTORY

日付は日本時間です。開始日・終了日を含めて検索します。ログは削除しません。


MYSQL DIAGNOSTIC
MySQL接続・権限を診断
接続先・通信の暗号化・専用利用者の権限を確認します。権限や設定を変更しません。


AP INTEGRATION
AP連携の確認事項
実機情報は未確定です。この確認はAPへ接続せず、設定変更や通信許可を行いません。


EVENT INFORMATION
学校祭の案内情報
空欄は未確定として表示します。日時は受付動作にも使う設定です。変更案を保存後、別の設定管理担当者へ内容の確認を依頼します。確認後、アプリ・定期処理を停止してサーバー端末で適用します。SSIDの機器設定は変更しません。
0 / 32バイト（前後の空白を除く）。空欄は未確定として保存します。


CONFIGURATION
設定・管理者
設定変更とアカウント管理は、導入手順に沿ってサーバー端末で行います。



WORKFLOW NOTICES
担当する確認・復旧作業
公開通知の詳細を、自分の権限と出力依頼の所有者に応じて表示します。取得不能を「問題なし」とは扱いません。


INFORMATION REVIEW
変更案の確認と反映
上の案内情報フォームで保存した案を、作成者とは別の設定担当者が確認します。適用はアプリ・定期処理を停止してサーバー端末で行います。


LEGACY PLAN
旧変更案を取り込む
サーバー担当が準備した確認資料の番号とSHA-256を入力します。元の案は保持し、新しい未確認の案として登録します。任意のファイルはアップロードしません。


CONSENT ARCHIVES
条件を指定した固定CSV
期限を過ぎた記録も保持しています。プレビューは出力対象の確定ではありません。出力準備が完了すると対象コピーが固定され、1ページ最大1,000件のCSVを取得できます。自分の依頼だけを表示します。「準備完了」「ページ生成」と、端末への保存完了は区別してください。
